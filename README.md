## Обзор

Обычный чат и работа с проектами в одном приложении. Chrome выполняет запросы к **Google Search AI Mode**, а Rust-клиент управляет вкладками через локальный Chrome DevTools Protocol. Интерфейс построен на системном **WebView2**, HTML/CSS/JavaScript и Mica/Acrylic — для работы готовой сборки не нужны Electron, Node.js или внешние CDN.

Это автоматизация веб-интерфейса, а не официальный API Google и не локальная модель. Интерфейс преимущественно русскоязычный; документация и блок «О приложении» доступны на двух языках.

## Быстрый запуск

1. Установите **Google Chrome** и **Microsoft WebView2 Runtime**, если их ещё нет.
2. Скачайте Windows x64 ZIP из [последнего релиза](https://github.com/ShinysLove/gemini-cdp-cli/releases/latest).
3. Распакуйте архив целиком в папку с правом записи. Оставьте `evil-gemini.exe`, `WebView2Loader.dll` и `config.json` рядом.
4. Запустите `evil-gemini.exe`. Если Chrome установлен по нестандартному пути, измените `chrome_binary` в конфигурации.
5. Выберите **«Чат»** для диалога или **«Работа»** для задач с кодом.

На Windows 11 используется Mica; на поддерживаемых Windows 10 — Acrylic. Эффект можно отключить в настройках. Доступность AI Mode зависит от Google, региона и аккаунта; авторизация не всегда обязательна. На первом запуске оставьте `headless: false`, чтобы вручную завершить вход, согласие Google или CAPTCHA.

## Возможности

| | Что доступно |
| --- | --- |
| **Чат** | Потоковые ответы, Markdown, поиск, локальная история, копирование и повтор запроса |
| **Вложения** | Выбор файлов, пути, перетаскивание и вставка изображений через Ctrl+V; миниатюры у черновика и отправленного сообщения |
| **Длинные запросы** | Текст свыше 12 000 символов отправляется как `message.txt`; текстовые вложения обычного чата читаются полностью |
| **Агенты** | 1–50 работников, зависимости DAG, стандартный, ручной или сгенерированный ИИ план |
| **Проверка правок** | Unified diff с номерами строк и подсветкой, отдельное подтверждение применения и сохранение результата |
| **Инспектор** | Изменённые файлы, журнал команд, пояснения модели и фактические вызовы инструментов |
| **Интерфейс** | Изменяемые размеры панелей, отдельные черновики режимов, плавные переходы с учётом уменьшения движения |

### Фото и документы

Вставка из буфера поддерживает **PNG, JPEG, WebP, GIF и BMP до 20 МБ**. Предпросмотр расположен внутри поля ввода. Отправленные изображения сохраняются с сообщением и открываются крупнее по нажатию. Старые сообщения без записанных сведений о вложениях остаются текстовыми.

Файлы хранятся как локальные копии с проверкой размера и SHA-256. Типовой предел — 20 MiB на вложение, до 10 файлов. В задачах агент видит предпросмотр текста, а полное содержимое читает порциями через `read_attachment`. PDF, изображения и DOCX загружаются через файловый элемент страницы, если текущая сессия Google это поддерживает; иначе отображается ошибка. Выбранное содержимое отправляется Google.

Подтверждение загрузки ожидается до **120 секунд** и учитывает имена файлов или новые миниатюры в поле Google. Повтор с тем же набором до отправки не дублирует загрузку. При CAPTCHA приложение показывает Chrome, ждёт ручной проверки и возвращает фокус своему окну; это ожидание не расходует тайм-аут ответа.

## Работа с проектом

1. Выберите папку проекта и опишите задачу.
2. В меню **«Агенты»** задайте число работников и при необходимости отредактируйте JSON-план DAG или запросите план у модели.
3. Запустите задачу. Независимые этапы выполняются параллельно, зависимые ждут предшественников.
4. Через **«Файлы и терминал»** просмотрите diff, журнал команд и вкладку «Действия».
5. Нажмите **«Проверить и применить изменения…»**, проверьте путь проекта и diff в отдельном окне, затем подтвердите запись. Статус «Изменения применены» сохраняется.

Каждый этап работает в частной копии снимка проекта с собственным Git-каталогом. Снимок включает незакоммиченные изменения и разрешённые неотслеживаемые файлы. Зависимости передают проверяемые правки следующим этапам; конфликтующие параллельные правки отклоняются. Перед применением повторно проверяются хеши исходников, чтобы не затереть новые изменения пользователя.

По умолчанию используются **3 работника**, не более **2 независимых анонимных бесед в одном Chrome** и общий интервал **5 секунд** между запросами. Пул бесед ограничивается отдельно; Chrome может показывать контексты отдельными окнами. Изменение числа работников влияет на новые назначения, сохраняя уже запущенные этапы.

После сбоя можно повторить незавершённые этапы текущей задачи без потери успешных результатов и исходного снимка. Повтор исполнения доступен до закрытия приложения. Сохранённые завершённые задачи можно просматривать и применять после перезапуска; автоматического возобновления незавершённых этапов нет.

При HTTP 429 действует общая пауза с учётом Retry-After, повтор — в той же сессии. Устойчивое ограничение останавливает оставшуюся работу без смены сессий ради обхода квоты. Отказ Google распознаётся как `SERVICE_REFUSAL`. Завершение этапа требует успешного вызова инструмента и корректного JSON-ответа `summary/done/actions`.

### Терминал и действия

Терминал — журнал команд и результатов, без интерактивного PTY или ввода в запущенный процесс. Ручная команда принимает имя программы и JSON-массив аргументов, работает в новой копии проекта и учитывает выбранный режим доступа. Отмена завершает принадлежащий приложению процесс и его дочерние процессы. Изменения ручной команды не включаются в агентский diff автоматически.

«Действия» показывает доступные ответы, пояснения, инструменты и ошибки. Скрытые рассуждения модели не предоставляются; протокол не исполняется как HTML/JavaScript.

## Режимы доступа

| Режим | Правила |
| --- | --- |
| **Ask for approval** | По умолчанию: подтверждение команд, patch/удалений и применения исходников |
| **Approve for me** | Автоматически разрешены валидированные patch/удаления в копии и стандартные `cargo check/build/test` с ограниченными флагами; другие команды, Git и применение исходников требуют подтверждения |
| **Full access** | Запросы инструментов выполняются без подтверждения; итоговое применение diff запускается отдельной кнопкой |

Изменение режима действует на следующие запросы и не одобряет уже ожидающие действия. Модель и содержимое репозитория не могут выдавать разрешения. Прямые файловые инструменты ограничены рабочей папкой: запрещены выход за её пределы, ссылки/junction, секретные каталоги и неоднозначные Windows-пути.

> [!WARNING]
> **Копия проекта не является песочницей ОС.** Одобренные команды и код сборки выполняются на вашем компьютере и могут обращаться за пределы копии. Проверяйте аргументы и рабочую папку перед подтверждением.

## Горячие клавиши

| Действие | Оконная версия |
| --- | --- |
| Отправить / новая строка | `Enter` / `Shift+Enter` |
| Запустить задачу | `Ctrl+Enter` |
| Новый чат или задача | `Ctrl+N` |
| Поиск | `Ctrl+K` |
| Чат / Работа | `Ctrl+1` / `Ctrl+2` |
| Прекратить ожидание | `Esc` или кнопка остановки; Google может продолжать генерацию |

Разделители панелей можно перетаскивать или менять стрелками с клавиатуры. Положение сохраняется локально. Оценка токенов — один токен на четыре Unicode-символа, а не расход, квота или биллинг Google. В задачах учитываются отправляемые контексты и ответы; в чате — история и черновик.

## Терминальная версия

```powershell
cargo run --locked --bin gemini-cdp-cli
cargo run --locked --bin gemini-cdp-cli -- --agents
```

Обычный CLI поддерживает текст и хранит историю в памяти. Каждый запуск начинает чистый диалог. `Enter` отправляет, `Ctrl+J` / `Shift+Enter` / `Ctrl+Enter` вставляют новую строку, `Ctrl+V` вставляет текст, стрелки прокручивают, `Ctrl+N` начинает новый диалог, `Esc` прекращает ожидание, `Ctrl+C` завершает клиент. Chrome остаётся открытым. Выбор модели через CLI не реализован.

В режиме `--agents`: `/workspace ПУТЬ`, `/attach ПУТЬ`, `/plan ФАЙЛ`, `/plan-ai ЗАПРОС` задают проект, вложения и план. `Tab` переключает фокус ползунка; стрелки, Home/End и мышь меняют число работников. `F4` показывает вложения, `F5` — diff, `/apply` запрашивает запись, `Ctrl+A` / `Ctrl+D` разрешают / отклоняют действие, `Esc` отменяет задачу. Вставка перетаскиваемых путей зависит от bracketed paste терминала.

## Конфигурация и локальные данные

Пример `config.json`:

```json
{
  "chrome_binary": "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe",
  "profile_dir": "profile_ai_mode",
  "cdp_port": 9223,
  "headless": false,
  "response_timeout_secs": 180
}
```

Запускайте CLI из папки с конфигурацией. Оконная версия ищет `config.json` в рабочей папке или рядом с EXE. Необязательный объект `ai_mode` переопределяет `input_selector`, `response_selector`, `stop_selector` и `complete_selector`; значения по умолчанию находятся в `src/ai_mode.rs`. Изменение разметки Google может потребовать обновления адаптера.

| Путь | Содержимое |
| --- | --- |
| `data/history.json` | Чаты, сведения о вложениях сообщений и настройки интерфейса |
| `data/workbench.json` | Выбранный и недавние проекты |
| `data/agents.json` | Доступ, работники, пул бесед (1–8), интервалы, шаги, повторы и лимиты вложений |
| `data/agent_runs/` | Отчёты, журналы и частные рабочие копии |
| `data/attachments/` | Копии выбранных файлов |
| `webview_data/` | Данные WebView2 |
| `profile_ai_mode/` | Отдельный профиль Chrome |

Эти пользовательские папки исключены из Git. Старый `profile_gemini` не переносится автоматически. Оконный и терминальный клиенты не должны одновременно управлять одним профилем/портом. Если вкладка не находится, закройте Chrome этого профиля и запустите клиент снова. При восстановлении чата открывается сохранённый адрес Google; если сессия недоступна, начните новый диалог.

CDP принимает только локальные WebSocket-адреса; не публикуйте порт в сеть. Приложение не меняет DNS, VPN и маршрутизацию: Chrome использует текущую сеть компьютера. Открытие рабочего пространства не создаёт бесед — подключение происходит при запуске задачи или открытии чата.

## Разработка

### Сборка Windows x64

```powershell
cargo build --release --locked --bin evil-gemini
.\target\release\evil-gemini.exe

# ZIP с EXE, загрузчиком WebView2 и документацией
.\scripts\package-release.ps1 -Version 0.1.2
```

В GNU-сборке `build.rs` копирует официальный `WebView2Loader.dll` из SDK рядом с EXE. HTML/CSS/JavaScript встроены в приложение. Для отдельного CLI используйте `cargo build --release --locked --bin gemini-cdp-cli`.

### Автоматические проверки

```powershell
cargo test --locked --all-targets
node --test tests/adapter.test.cjs tests/workbench.test.cjs tests/desktop-ui.test.cjs
```

Обычные тесты не обращаются к Google. Ошибки отправки сохраняют черновик; Markdown экранирует HTML модели и запрещает исполняемые ссылки. CLI восстанавливает терминал при выходе и ошибках.
